# Tanzil Quran Dataset

Le fichier `tanzil_quran_simple.xml` a ete telecharge depuis la page officielle Tanzil.
Le fichier `tanzil_quran_simple.json` est une conversion interne par verset pour le backend.
Le fichier `en-tafisr-ibn-kathir.json` est un tafsir local ajoute depuis une page trouvee sur Qul by Tarteel.
Les fichiers `Sahih Muslim.json`, `Sahih al-Bukhari.json`, `Jami\` at-Tirmidhi.json`, `Sunan Abi Dawud.json`, `Sunan Ibn Majah.json` et `Sunan an-Nasa'i.json` proviennent du dataset Hugging Face `meeAtif/hadith_datasets`.

Source officielle:
- https://tanzil.net/download/

Source tafsir mentionnee:
- https://qul.tarteel.ai

Source hadith mentionnee:
- https://huggingface.co/datasets/meeAtif/hadith_datasets

Rappel important:
- le texte du Coran ne doit pas etre modifie
- la source Tanzil Project doit etre clairement attribuee
- un lien vers `tanzil.net` doit etre conserve dans l'application ou sa documentation
